# GradHeat Vue 工作台

Vue 3 单文件组件 + TypeScript + Vue Router + Vite；ECharts 按路由延迟加载。深绿导航、浅色数据面板、紧凑列筛选浮层；没有 CDN、图片外链、真实资料 fixture 或隐藏的数据回退。

## 运行与验证

在本目录运行 `npm ci --ignore-scripts`、`npm test`、`npm run build`。本轮固定 Node 22.19.0；Vite 7.3.1 要求 Node 20.19+ 或 22.12+。[Vite 官方文档](https://vite.dev/guide/)

`npm run dev` 使用 127.0.0.1 开发服务，`/api/v1` 代理到 Java 的 18729，保留 Host/Origin。生产构建为 `dist/`，由统一入口静态托管，`/api/v1` 始终进入 Java。浏览器不直连 Python、MySQL、Redis 或 RabbitMQ，也不持有服务认证密钥。

任务状态、版本、即时计算和保存协议见 [共享合同](../contracts/application-v1/README.md)。保存比较由 Java 在本机业务写入配置启用后处理；前端不自动启用服务权限。

## 页面与组件

- 招生计划：全局搜索、科目范围、可折叠条件；每列独立搜索、选值、升降序；固定表头。
- 历年录取：年度切换、单列过滤、复录比与字段核对状态；独立折叠的校线 / 院线及名单分组表保留年度、专项、调剂与人群口径。
- 院校图览：原计划与 2025/2026 同范围历史；含推免与统考口径保留。多范围或未知数字不绘图。
- 平台热度：读取已提交的有界样本；每 60 秒刷新已存数据，真实采样时间另列；无样本不记为热度零。
- 比较：2—8 项并排展示（单项也可偏好比较），个人适配区间、权重、草稿、保存/读回/导出。
- 偏好推荐：不用初试分数，专业和用户指定的类别偏好；双非友好证据不足保持待核，不加分。
- 博弈情景：2—8 个候选、显式假设容量/人数/偏好、需求敏感性；不是录取预测。
- 更新记录：显示本浏览器已记录的任务状态；不把空列表说成后台没有任务。

`AdmissionsTable.vue` 负责列状态与弹层；`table.ts` 独立处理过滤与排序，升降序都将未知值留在末尾。`api.ts` 唯一请求入口，保留版本冲突错误；比较、推荐和情景条件改变后清除旧结果并保留填写。

移动端缩小表格字体并换行，所有列仍在屏幕内；全局筛选默认折叠，导航改底栏。列弹层可用 Escape 关闭；所有按钮提供中文可访问名称，动画尊重系统减少运动设置。

## 已验收范围

`npm test` 通过 13 个单元测试；`npm run build` 完成真实类型检查和生产构建。生产入口约 121 kB，图表约 512 kB，仅图览/博弈页延迟加载；图表包仍有 Vite 的 500 kB 提示，未声称性能已经完成实网评估。
