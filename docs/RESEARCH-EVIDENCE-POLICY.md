# 招生证据与博弈模型研究规范

## 从检索到事实

优先教育部、研招网、学校研究生院及学院原始公告；招生目录、调整通知、复试细则与拟录取名单分别核对。年份、专业代码、校区、方向、学习形式、一志愿/调剂、推免/统考和专项计划必须一致。搜索摘要和转载只作线索；多篇转载同一公告不算独立交叉验证。

每项进入模型的重要事实至少记录以下字段：

| 字段 | 要求 |
|---|---|
| claim_id / claim | 唯一编号和可核对的具体陈述 |
| source_url / issuer | 原始链接与发布机构；论文记录作者及 DOI/arXiv ID |
| published_at / retrieved_at / available_before | 发布与采集时间，以及历史决策截止前是否可获知；未知明确标记 |
| cohort / pool / definition | 招生年度、群体、计划/实际口径；人数分母定义 |
| locator / excerpt | PDF 页码、表格行列或正文段落；短摘录及上下文 |
| artifact / sha256 | 原始附件或响应的受控存储路径、哈希、版本 |
| verification | metadata-only、abstract-read、passage-verified、full-text-reviewed |
| conflicts / limitations | 冲突来源、缺失值、修订及无法验证的事项 |

原始响应的哈希只能证明留存版本一致，不能证明内容为真。官网内容冲突时核对发布主体、修订时间与适用范围，保留两版及处理理由；未解决的不进入确定性结论。PDF/OCR 数值须回看原页，缺失不填零，抓取失败不解释为学校未发布。

## 从事实到量化

资格与考试科目先作为硬约束。热度、竞争程度、录取概率、就读效用分别建模，不能把任意加权热度直接当概率。区分初试入围与入围后录取的条件概率；推免占用、扩招、调剂及复试规则变化单独处理。

历史验证按时间切分，特征只使用报考截止前已公开的信息。以招生人数、规则变化和往年位次等简单基线比较；概率预测检查校准、Brier/log loss 和分组误差。数据不足时给情景范围与适用限制，不给无依据的精确百分比。效用权重来自考生偏好，并做权重敏感性分析。

## 博弈论的适用边界

模型必须明确玩家、行动集合、容量、报考与信息发布时间、可观察信息、成绩与偏好不确定性及收益定义。考生预测其他考生选择，是可能的拥挤机制；是否形成周期、均衡以及能否用来预测，都需要另行验证。

- 拥挤博弈：只有明确满足相应模型条件，才能引用势函数或纯策略均衡的存在结论；存在不等于唯一、快速收敛或现实可预测。
- 动态反馈：择校推荐可能改变报考分布，历史数据不是永久不变的环境。需检验推荐采用率、反应滞后、容量变化等情景。
- 所谓“大小年”：少量年度交替不能证明周期。先排除招录口径与政策变化，再用留出的未来年度检验，并与无周期基线比较。
- 机制匹配：不能将高考平行志愿或稳定匹配机制直接套到研究生一志愿加后续调剂的制度；必须依据当年规则分别描述阶段。

最终输出应分开写“观测事实”“模型假设”“在这些假设下的结论”“历史检验结果”。不把均衡存在定理包装成择校成功保证。
