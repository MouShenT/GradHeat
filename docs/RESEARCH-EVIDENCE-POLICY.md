# 数据核对约定

官网、社交资料与合理交叉核对共同用于院校档案。保留原始来源、取得时间和原件 SHA；搜索摘要只作线索，正文和附件用于实际数据。转载、fork 与同一来源链不重复计票。

按院校、院系、专业、年份、方式与招生人群匹配。普通一志愿、调剂、专项、推免及复试/录取不同口径分开。计划含推免不自行当作净统考名额。

合理范围的数值和背景经验可按证据权重进入档案；明显离谱、相互冲突或范围不明的信息保留缺口。官方明确反值不被社会帖子覆盖。未知不填零，访问失败不解释为没有公布。

院校独立择校站也是来源。保留网站、重要页面和表格原文，标明社区整理；学硕/专硕通用线保持通用范围，普通和专项、11408/22408 分开。没有同年度官方或已对齐历史值时，合理且范围匹配的社区表格可按有限置信权重参与，不能覆盖官方明确反值。同导航及其转载链不重复增加独立票数，网站 IP 访问量不作为搜索指数。

专题站的名单接口保留原 JSON 并重解析校验，院校和专业身份须与请求相符。名单最低分与官网公布复试线分开；仅有录取名单时，站点所报未录零条不证明淘汰率为零。脱敏编号可能碰撞，统计为观测行并保留人数未核；完整编号的重复行只有成绩与人群范围一致才去重，冲突整份暂缓复核。对外只展示白名单汇总字段，不输出考生标识、原件路径或任意嵌套原 JSON。

热度只使用实际讨论和真实搜索观测。胜利指数明确个人条件与模型假设，是参考值。后续按时间切分和基础模型检验，再调整参数；当前不包装成已校准录取概率。

真实材料、院校记录、搜索序列和具体研究报告留在本地与 MySQL；远程只提交算法、模板、合成测试及维护文档。
