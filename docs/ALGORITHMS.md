# 热度与胜利指数

热度按平台和内容 ID 去重，保留最新观测。互动计数做对数压缩和上限约束，按 90 天衰减；多院校帖子按归属数分摊。计算已有样本的平台均值，不把缺失平台填零。

实际搜索信号按参考尺度 1000 做有界变换，保留时间窗与覆盖率。搜索数据存在时热度由 65% 讨论信号与 35% 搜索信号组成；没有搜索时给讨论估算并标明依据。没有可用信号则为空，搜索结果数量不替代用户搜索热度。

百度指数通过固定版本 Qdata 采集，使用本机登录状态；Cookie 留在忽略目录。未收录、缺值、登录失效和受限分别记录，只有实际观测进入档案。

胜利指数先匹配年度、专业、科目、方式与人群，再结合预计总分或完整单科分数、背景、层次意愿、容量和热度。分数采用有界 logistic 转换，其他项按有限权重参与；容量与选择收益的拥挤情景进入指数。

用户可在网页填写并保存本机草稿，未填分数不生成个人指数。同口径历史缺失保留缺口；合理社交资料按证据权重参与，不能覆盖明确相反的官方事实。

指数是相对参考，尚未校准为录取概率。后续以留出年度和基础分数/容量模型检验。公式唯一实现于 `python_service/gradheat_core/intelligence.py`、`congestion.py`。
