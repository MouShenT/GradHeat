# 热度与胜利指数

共享模型版本为 `school-heat-victory-v2`。网页主表各显示一个热度值、一个个人胜利指数；个人条件允许以后填写。缺值不填零。

## 热度

按平台和内容 ID 保留最新观测。互动计数做对数压缩与上限约束，按 90 天衰减；多院校帖子分摊权重。已有样本的平台求均值，缺失平台不参与分母。

真实搜索指数按 `100 × (1 − exp(−value/reference_scale))` 有界转换，再按窗口时效衰减。每个提供方、关键词、地域和设备只用最新窗口；总设备指数与 PC/移动指数不重复相加。连续两周各有至少 5 天实际观测时，加入最多 ±5 分的趋势调整。缺失日不补零。

两类数据都有时，热度为 65% 讨论与 35% 搜索；只有一类时使用该类并保留依据。搜索结果条数不替代搜索热度。覆盖率和时效用于资料覆盖评分，不是第二个热度值。

百度指数沿用固定版本 Qdata 与本机登录。原始响应、真实日序列和不可变字节存入 MySQL；未收录、缺值、登录失效、访问拒绝、浏览器连接失败分别记录。012 迁移单独保存规范字节，避免 MySQL JSON 浮点重排改变原始序列。

唯一实现：`python_service/gradheat_core/heat_index.py`。`heat.py` 保留已有热度服务的缓存与摘要。

## 院校输入

官网事实保留年度、院系、代码、方式、校区、一志愿/调剂/推免、普通人群或名单样本及原件定位。合理核对后入库，原件和记录 SHA 读回一致。网页仅投影重要数值。

只有明确“不含推免”且专业/方向口径唯一的当前计划才转为净名额。名单样本人数不当招生名额；历史名额或录取数仅作为标明年度的容量参考。复试线、录取均值与权重按同院校、代码、院系、方式和人群匹配，改考增加不确定性。冲突、跨代码或缺失继续留空。

输入实现：`decision_inputs.py`；不可变事实校验入库：`gradheat_python/school_facts.py`。新增 011、012，已有迁移不改字节。招生发布版本不因补充档案而改写。

第三方院校指南通过 `collect_community_sources.py` 收集显式登记的站点、有限站内页面和分数原文，013 保存不可变网站快照。按院校独立归档，网页显示来源和普通/专项分数表。范围明确的普通 11408 分数表可在同年度没有官方或已对齐历史值时作为参考，置信权重 0.6；不把学位类别通用线虚构为历史专业代码，也不把 22408 或专项线套到普通 11408。转载来源链不增加独立票数，网站访问量不替代真实搜索与社交热度。

## 容量博弈

市场先包含全部符合目标年度 11408 且具备热度和正容量的竞争池，再应用个人院校筛选、学习方式和显示数量。共享专业名额只计一个池；矛盾容量不强行合并。

令 `cᵢ` 为容量占比、`xᵢ` 为选择份额、`aᵢ` 为热度和层次形成的吸引项，在 `Σxᵢ=1` 下最小化：

`0.5 × κ × f × Σ(xᵢ²/cᵢ) − Σ(aᵢxᵢ) + τ × Σ(xᵢlog xᵢ)`。

`κ=1.2`、`τ=0.8`。一阶条件与乘子二分求解，检验份额守恒及驻点残差。压力为 `f × xᵢ/cᵢ`，计算 `f=0.75、1、1.25` 三种相对拥挤情景，不推测真实报考人数。势函数与拥挤均衡的联系参见 [MIT Networks 原始讲义](https://ocw.mit.edu/courses/14-15j-networks-spring-2018/resources/mit14_15js18_lec15/)。熵项、吸引项和参数是本项目的建模选择。

唯一实现：`market_game.py`。

## 个人胜利指数

预计分数经 logistic 转换，目标分参考复试线和同年度录取均值。分数、层次意愿、用户自评机试/项目能力、净名额按有限权重组合，扣除热度、均衡拥挤及复录比压力。已有同专业背景资料按用户明确填写的条件有限参与，不从本科名称猜测层次。

当前年度明确禁止的报考条件、当年已知单科线不满足、明确零名额时指数为零。历史单科线与限制只作为参考风险。没有匹配分数资料时个人指数为空。

历史波动、改考和缺值形成分数上下情景，与三种拥挤情景交叉得到范围。风险偏好从冲刺 0 到稳妥 1，将基准指数向保守值移动。资料覆盖考虑分数来源、容量和实际热度覆盖。网页可展开计算依据。

唯一实现：`victory.py`，经 `intelligence.py` 公共入口调用。

## 检验与局限

合成测试检查分数单调性、风险偏好、筛选不改变市场、共享名额去重、份额守恒、驻点残差、来源口径及未知/零的区别。`tools/research/evaluate_index_models.py` 对本机实际数据生成覆盖与反事实检验报告。

历史诊断只留出最新年度复试线，使用更早年度预测，按竞争池去重并排除已知改考。它衡量复试线稳定性；尚缺完整决策前时间戳和个人录取结果，不能声称胜利指数是录取概率，也不自动拟合权重。诊断和真实材料保存在忽略目录。
