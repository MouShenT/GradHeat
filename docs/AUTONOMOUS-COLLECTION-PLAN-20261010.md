# 独立Python采集服务：方案、现状与实施计划

2026-10-10。程序输入一个JSON，指定官网、小红书、知乎、抖音、B站、GitHub及对应搜索内容；独立执行、保存原材料，结束后交给用户整理分析。执行不需要Codex、Java前端或RabbitMQ在线。运行材料不提交Git。

用户最新规则：**登录、验证码、格式异常或内容未取得时，记录缺口，继续后面的任务；结束生成未完成JSON。整个程序不等待人工、不因一个平台阻塞而暂停。** 已受限平台后续查询标记“未请求：平台受限”，避免重复触发验证；其他平台和官网继续。未请求的任务不能称为实际遇到验证码。

## 单一输入接口

参考config/collection-input.example.json。唯一用户输入为tasks数组，每项包含platform和query；官网可补urls/domains/unit，GitHub可直接给repo。limit控制数量，社交可给实际支持的sort。平台接受英文短名及中文别名。settings可在同一个JSON覆盖有界预算，不需要用户维护三份配置。

输入冻结成input.json/plan.json/queries.json，保存SHA和任务ID，按照输入顺序执行。--batch续跑原检查点，成功任务不重采。incomplete.json使用相同输入格式，只含尚未取得完整材料的任务和失败说明，可直接发起补采。原批次、旧原件、旧失败结果保留。空结果也进入缺口，不表示信息不存在。

## 新架构中的位置与现状

Vue负责数据、比较、推荐与任务页面；Spring Boot负责公开业务API、个人比较与任务账本；Python负责采集、原件、提取和算法。RabbitMQ连接应用发起的耗时任务。独立采集CLI复用Python能力与采集锁，直接写MySQL，不以Java/RabbitMQ可用为前提。Redis只是可重建缓存；本入口不自动发布招生数据，不改写个人比较。

已有官网公开HTTP/浏览器回退、四平台MediaCrawler适配、抖音正常搜索响应观察、MySQL原件字节档案、SHA与冻结恢复。应用的真实Java→Rabbit→Python→MySQL→Java分析链通过42项验收，不能用它证明所有采集渠道可用。旧冻结全量队列不被新入口重启。

## 各渠道

| 渠道 | 获取方式 | 失败处理与边界 |
|---|---|---|
| 官网 | VM现有SearXNG检索原词；指定域名则限制搜索；抓取公开正文、附件、内嵌图表和有界链接 | 纯查询默认接受edu.cn/ac.cn/chsi.com.cn；其他官网明确给域名。HTTP受限可正常公开浏览器加载；验证页不是招生原件。搜索服务故障单记缺口，已给URL仍可抓取 |
| 小红书/知乎/B站 | 预先登录专用Chrome，MediaCrawler客户端检索和详情；通用输入保留平台结果顺序，不暗中按计算机相关性丢弃 | 一次受限后登记状态，后续查询标记受限未请求，不等待用户。保存正文/公开图片及计数；说明不冒充完整视频转录 |
| 抖音 | 专用Chrome正常加载搜索，观察本次真实搜索响应 | 当前为综合排序，不重放旧签名；verify_check不能当作正常空结果 |
| GitHub | REST仓库检索，冻结选中仓库，固定commit ZIP快照 | 公开仓库搜索或直接repo，不是全GitHub代码搜索；鉴权/限流、空结果、异常结构、ZIP异常登记缺口 |

GitHub检索按[官方文档](https://docs.github.com/en/rest/search/search#search-repositories)，固定版本归档参考[官方说明](https://docs.github.com/en/rest/repos/contents#download-a-repository-archive-zip)。搜索回执保留查询上下文，不算官方招生正文；fork不增加独立验证票。

社交查询至少间隔30秒，详情3秒，关闭评论与视频下载；每关键词当前一页，最多20条详情。官网默认每任务60页、深度3、单件50MB；GitHub单件150MB。预算可在JSON调整。运行不调用语言模型；遍历固定计划不代表全站或全国材料完整。

## 存储、恢复与交接

原件先落本地不可变检查点，取得SHA，再写MySQL原件字节及采集账本并读回。入库失败继续其他任务，原件保留；--batch --only-ingest仅续传原批，不重新搜索。存在原件必须通过哈希检查，恢复不得覆盖。Windows任务目录使用短ID，完整ID仍在账本。

公开包包含原件、转录、查询上下文、manifest、SUMMARY.md、summary.json、missing.json、incomplete.json与SHA索引；重复字节只放一份，查询与来源关系仍保留。禁止导出Cookie、请求头、签名、令牌、私有日志和会话HTML/HAR。社交仅保存清洗后的公共内容，不保存登录页面。取得字节与内容完整分开。

验证码、登录、格式异常、空内容、附件缺失、预算未执行、入库失败、受限未请求分别保留。结束分别报告固定队列处理完和资料完整，数据库提交成功不能掩盖缺口。

用户交回批次目录或handoff.zip后，再核对招生年度、院系、专业、统考/推免/专项等口径，执行同招生事项两源一致。经验帖不自动变成双非友好评分，热度样本不自动变成报考人数或录取概率。
