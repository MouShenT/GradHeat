# 多平台关注度与报考意向信号

2026-09-23。当前为设计方案，尚未接入四个平台采集，也没有真实跨平台热度评分。此模块补充官方招生数据，不能替代招生计划、资格和录取规则。

用户已明确学习研究用途。非官方采集路线采用 **MediaCrawler 首轮统一试点，xhs/F2 按需专项对照**，而不是仅等待官方全站搜索接口；仓库核验、平台限制及可靠性验收见 [采集项目选型](SOCIAL-COLLECTOR-SELECTION.md)。下表的官方路径状态不代表排除研究采集路径。

## 平台与获取路径

| 平台 | 拟观察的信号（仅在实际可取得时） | 接入判断 |
|---|---|---|
| 小红书 | 择校笔记、收藏/评论变化、求比较与报考意向表达、机构内容占比 | 本轮官方文档确认授权/电商能力，未确认可直接使用的全站笔记搜索接口；先小样本人工核验或有明确授权的数据服务 |
| 抖音 | 相关视频新增、互动变化、独立作者、集中推广与话题爆发 | 官方有搜索能力，但需申请且有场景约束；不能假定本项目已经获准或具备历史全量回溯 |
| B站 | 长视频经验分享、播放/收藏/评论变化、内容年龄与作者分布 | 官方开放平台说明授权用户及稿件数据；不能据此推断拥有全站关键词数据接口，先验证公开样本路线 |
| 知乎 | 相关问题/回答新增、赞同/评论变化、报考顾虑及规则争议 | 官方数据平台公开搜索 API 与鉴权说明；可优先评估正式接入，仍需实际账号权限、字段与覆盖测试 |

官方依据：[小红书 SDK 能力](https://open.xiaohongshu.com/document/developer/file/42)、[B站开放平台](https://openhome.bilibili.com/doc)、[知乎数据平台](https://developer.zhihu.com/)、[抖音搜索能力](https://developer.open-douyin.com/docs/resource/zh-CN/dop/ability/search-management/item-search)。抖音另有[关键词视频接口](https://partner.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/search-management/keywords-video-list/keywords-video)，文档规定权限申请和较短时间窗口；不同产品接口的能力不能混写。

这些是文档核验，不是接口实测。Exa/Firecrawl 可发现公开索引内容，但不能保证站内覆盖，更不能用搜索引擎估算结果总数充当平台热度。平台缺数据时标 unavailable，不填零。

## 指标必须拆开

1. **内容供给**：固定检索条件下新增且相关的内容数、独立作者数，衡量讨论供给。
2. **关注互动**：同一批内容两次快照之间的播放/收藏/评论等增量，各指标保留各自含义；播放不是人数，收藏不是报考。
3. **意向表达**：样本中明确提到目标年度、院校专业的报考/换校/观望表达占比；仅为样本表达，不等于真实报名率。避免汇集个人身份画像。
4. **传播集中度**：头部作者/内容占比、疑似推广占比、重复文案与跨平台搬运，识别少量爆款推动的表面升温。
5. **变化趋势**：平台内部同口径 7/30 日趋势与季节基线；窗口长度是初始设计，需要样本验证。

首版展示平台分面趋势，不直接给一个跨平台总分。若后续确需综合指数，只能在各平台内同窗口、同采样方法标准化，再报告权重、可用平台集合及敏感性。某平台缺失时不静默重分权重；与上期比较使用共同可用平台或标记不可比。

## 实体、采样与可比性

关键词由学校全名/可靠简称 + 学院/专业 + 408/考研 + 目标年度组成，同时保留泛学校词与精准专业词两个层级。简称歧义、其他考试、招聘、本科招生等先过滤；单纯提到学校不能直接归到某个竞争池。院校级和池级信号分开。

记录 platform、query_version、sort_mode、time_window、page/cursor、collection_route、account/region sampling context、collected_at、returned_count、truncated 和失败原因。账号采样上下文仅保存必要的非敏感标签。个性化与默认排序导致的样本偏差必须披露。

固定采样预算内，默认排序用于观察可见度；若平台提供时间排序，再单独观察新增。不能将不同排序混合计数。截断的 Top-K 结果表示样本，不声称全站总量；同样 K 下内容数经常饱和，也就不能有效衡量升温。

以平台内容 ID 去重，保留内容发布时间与采集时间。互动增量只比较同一内容且字段定义相同的两次观察；新增内容另列，缺失不视作零。负增量保留并标记可能修正，不一律截成零。删除/不可见与零互动分开。

跨平台转载聚类用于检查共同起源，不跨平台推断同一自然人。作者或机构的多条内容不能当作等量独立需求。文本分类器需人工标注样本检验相关性、广告和意向类别，错误率按平台报告。

## 与择校连接

数据路径：平台适配器 → 检索批次与内容快照 → 实体消歧/去重 → 平台内指标 → 趋势与传播结构 → 情景假设。该路径与官方事实库隔离，仅通过明确实体映射关联。

第一阶段只解释“讨论在升温”“由少数机构集中推广”“关注与明确意向不一致”等观测。需求上升情景的幅度由显式假设给定，不机械地把热度上涨 20% 换算成报名上涨 20%。

只有在报名截止前冻结历史信号，并控制计划、科目、规则和共同年份因素后，热度模型相对无热度基线有稳定样本外增益，才考虑进入概率层。某校分数变化不自动验证热度因果关系。

优先补查可能改变当前选择的来源。热度用于提示进一步核查名额、规则或讨论起因，不用于覆盖官方证据或给学校贴“稳”“必爆”标签。

## 试点顺序与验收

先选 3—5 个已核验竞争池及对应院校词，四个平台都建立小规模人工样本，验证相关性和字段。自动化顺序由权限、持续可取性与复核成本决定；目前知乎有官方搜索文档，值得优先测试，不把平台体量当作接入优先级。

连续观察建议至少 4 周，用于验证采集稳定性及样本变化，不用于证明跨年预测价值。记录相关内容精确率、重复率、作者集中度、有效快照率、截断比例、人工复核分钟数和服务费用。授权不足或字段不可得的平台先人工/定性降级，不能以持续逆向和加大重试支撑主流程。

验收时要能明确回答：到底采到了什么群体、漏掉什么、趋势是否由采样变化造成、能否复算、是否改变了实际择校情景。未达到这些条件，不发布综合热度排名。
